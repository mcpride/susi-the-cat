# Text editor

The tab *Text editor* at the bottom shows everything about the selected text of the current
language. It opens with the ✏ button above the sheet or with a double-click on a multi-line text.

## Left: original and translation

- *Original* shows the text in the original language. It cannot be changed here.
- *Translation* is the translation in the current language. Changes are taken over immediately.
- If the row has a maximum length, a counter below shows the characters used, for example
  `42 / 40 characters`. It turns red when the translation is too long.

## Middle: comments

- *Row comment*: a note on the row that applies to all languages, for example from the
  developers.
- *Translation comment*: a note on this translation only, for example a question to the reviewer.
  It can be entered as soon as the cell has a translation.

## Right: properties and suggestions

- The buttons ⏮ ◀ ▶ ⏭ move to another row.
- The colored entries set the status of the translation.
- Below: row status, context, source file and whether the row may be translated.
- *Translation memory*: translations of equal or similar texts with their similarity in percent.
  *Apply* takes over a suggestion. See [Translation memory](translation-memory.md).

For pictures and other binary data, the tab shows the pictures instead, see
[Pictures and binary data](pictures.md).
