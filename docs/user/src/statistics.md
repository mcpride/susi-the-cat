# Statistics and reports

The tab *Statistics* shows how far the translation is. Open it with *Project › Statistics* or the
📊 button in the toolbar.

- The first line counts the rows, words and characters of the originals, and the rows marked *Do
  not translate*.
- The second line counts the rows by row status, for example how many are *New*.
- The table shows one line per language: the progress in percent, the number of translations per
  status, and the words still open.

## Saving a report

*Project › Save report…* saves the statistics as a file, for example to send it to a project
manager:

- **HTML** (`.html`): a page for the web browser.
- **Text** (`.txt`): plain text.
- **JSON** (`.json`): for further processing by other programs.
