# Keyboard shortcuts

On macOS, use `Cmd` instead of `Ctrl`.

## Everywhere

| Keys | Command |
|---|---|
| `F1` | Help for the part of the window under the mouse pointer, or for the open dialog |
| `Ctrl+N` | New project |
| `Ctrl+O` | Open project |
| `Ctrl+S` | Save project |
| `Ctrl+F` | Find (tab *Search results*) |
| `F5` | Scan for changes |
| `F9` | Build |

## In the translation sheet

| Keys | Command |
|---|---|
| `↓` / `↑` | Next / previous row |
| `Home` / `End` | First / last row |
| `F2` or `Enter` | Edit the selected cell |

## While editing a cell

| Keys | Command |
|---|---|
| `Enter` | Keep the text and move to the next row |
| `Esc` | Cancel the change |

## In the tab Screenshots

| Keys | Command |
|---|---|
| `Ctrl+V` | Paste an image from the clipboard as a screenshot of the selected row |
