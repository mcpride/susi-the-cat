# Output

The tab *Output* is Susi's log. It lists what happened, with time and type:

- *Information*, for example "Project opened", the result of a scan, every file written by a build,
  or the number of texts found by a search.
- *Warning* and *Error* (in color), for example a source file that could not be read.

Look here first when something did not work as expected. New entries appear at the bottom. *Clear*
empties the list.
