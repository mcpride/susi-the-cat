# Options

*Tools › Options…* contains the personal settings. They apply to all projects.

| Setting | Meaning |
|---|---|
| *Translation memory (TMX)* | The file of the [translation memory](translation-memory.md). Empty: the default file in the settings folder of Susi. |
| *Minimum fuzzy match* | How similar a text must be, in percent, to be offered as a suggestion from the translation memory. |
| *User interface language* | *Automatic (system language)*, *English* or *Deutsch*. Takes effect immediately. |
| *Automatically save translated texts<br>to the translation memory when saving* | Adds your translations to the translation memory every time you save the project. |
| *Show "Context" column*,<br>*Show "Row comment" column*,<br>*Show "Translated on" column* | The optional columns of the [translation sheet](sheet.md). |
| *Dark theme* | Dark colors instead of light ones. |

The columns and the dark theme can also be switched in the menu *View*, the user interface
language in *Tools › User interface language*.

## Where Susi keeps its settings

Susi keeps the settings, the default translation memory and the size and position of its window
in a settings folder of your user account:

- Windows: `%APPDATA%\susi`
- Linux and macOS: `~/.config/susi`
