# Languages

A project has one original language per source and any number of target languages, the
languages you translate into.

## Adding and removing languages

*Project › Languages…* shows the original languages and the target languages of the project.

- To add a language, choose it in the list next to *Add:*, or type its code in *ID:*, and click
  *Add*. Codes follow the usual conventions: `de` for German, `de-CH` for Swiss German, `pt-BR`
  for Brazilian Portuguese, `zh-Hans` for simplified Chinese.
- To remove a language, click *Remove* in its line and confirm. All translations of the language
  are deleted.

The column *Kind* shows *Target* for normal languages and *Pseudo* for
[pseudo languages](pseudo-translation.md).

## The current language

Many commands work on the current language, for example *Column* and the translation status
filter. Choose it in the toolbar (*Language:*), at the end of the menu *View*, or click a cell in
a language column.

## Showing languages

- *View › All languages* shows all languages side by side.
- *View › Single language* shows only the current language, with its status and comment.
- *View › Additional languages* chooses languages that are also shown in the single-language
  view, for example German as a reference while translating into Swiss German.
