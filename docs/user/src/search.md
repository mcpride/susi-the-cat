# Search

The tab *Search results* finds texts in the whole project without hiding any rows.

1. Choose *Search › Find…* (`Ctrl+F`), or click the tab *Search results*.
2. Type the text in *Find what:* and press `Enter` or click *Search*.
3. Choose where to search: in all columns, the original, the translation, the context or the
   comment. *Match case* distinguishes upper and lower case.

The list shows the context, the original and the translation in the current language of every
hit. Click a hit to select its row in the sheet. The number of hits is shown in the tab title.

*Use as filter* copies the search into the filter bar, so the sheet shows only the matching rows.
See [Filter bar](filter.md).
