# Comments

Comments carry information between developers, translators and reviewers. There are two kinds:

- The **row comment** belongs to the text and applies to all languages, for example a hint from
  the developers like "button label, max. 12 characters".
- The **translation comment** belongs to one translation, for example a question about the
  meaning or a note for the reviewer.

## Where comments appear

- A small triangle at the top right of a cell shows a translation comment.
- The column *Row comment* shows the row comments (switch it on in the menu *View*).
- The tab *Comments* lists all rows of the current view that have a row comment or a translation
  comment in the current language. Click an entry to select the row.

## Writing comments

- In the [text editor](text-editor.md): *Row comment* and *Translation comment*.
- In the row properties: *Row › Properties…*.

Comments can be included in exports, so external translators see them, and imported with their
answers. See [Exchanging files](exchange.md).
